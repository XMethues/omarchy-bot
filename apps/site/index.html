Installation guide ↗
Run in your Omarchy terminal 
omarchy plugin add https://github.com/XMethues/omarchy-bot.git --enable

Use the command above to install and enable the plugin.

Before you get started.

Is this a cloud agent service?+

No. The daemon, Agent workers, and Bot Computer run on your Omarchy machine. Your Agent may still use cloud model providers, so local execution does not mean all data stays offline.

Which Agents can I use today?+

Pi is the currently implemented backend. Other Agents need their own adapter and verified capability support before they become selectable. The future Tauri client is not a separate execution backend.

Can I connect Google or install Skills here?+

Use Plugins in the Bot Client to search and install Skills. Service account connections are not available yet. These public pages never connect to your local daemon.

Can I expose the client to the internet?+

The current daemon has no application authentication. Anyone who can reach it may control Bots and their screens. Do not treat it as a secure remote-access service; client authentication is required before public release.

What happens when I delete a Bot?+

Its plugin-owned records and targeted Screen runtime are removed. Shared Workspace files, Agent-owned Native Sessions, and shared Bot Computer application state are preserved.

Is Omarchy Bot free?+

The source is available under the MIT license. Your model provider and any third-party services you use may charge separately. There is no hosted subscription checkout on this website.
